# Sparse Matrix Operations

파이썬을 이용해 희소 행렬(Sparse Matrix)의 기본적인 수학적 연산을 구현한 프로젝트입니다. 메모리 효율성을 극대화하기 위해 행렬을 DOK(Dictionary of Keys) 포맷으로 다루도록 구현되었습니다. 

## 프로젝트 구조
- `src/`: 핵심 소스 코드 디렉토리
  - `main.py`: 희소 행렬 연산 시연 스크립트
  - `utils.py`: 행렬 덧셈 및 스칼라 곱 등의 연산 함수 모음
- `docs/`: 문서 디렉토리
  - `README.md`: 프로젝트 설명

## 주요 기능
1. **희소 행렬 덧셈**: 두 개의 서로 다른 희소 행렬의 동일 좌표 값 병합
2. **스칼라 곱**: 희소 행렬의 모든 비영(Non-zero) 요소에 대한 상수배 연산
3. **Dense 변환 출력**: 직관적인 시각화를 위해 희소 행렬을 일반 행렬 형태로 터미널에 출력

## 실행 방법
로컬 환경에서 다음 명령어를 통해 테스트해 볼 수 있습니다.
```bash
python src/main.py
